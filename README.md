## Featured Projects

### [API Abuse Detection using ML](https://github.com/nishantwhat/api-abuse-detection)
**Anomalous request detection from Layer-7 HTTP traffic logs**
- Feature extraction pipeline: lexical properties, behavioral patterns, request-level statistics from nested JSON logs
- Ensemble classification: Logistic Regression, Random Forest, Gradient Boosting with hyperparameter optimization
- Evaluation metrics: F1-score, Precision, Recall, ROC-AUC across attack/benign classes

### [SecureFS](https://github.com/nishantwhat/securefs)
**Cryptographic file system with tamper-evidence and secure deletion**
- AES-256-GCM authenticated encryption with PBKDF2 key derivation and iteration tuning
- Interface-driven modular architecture for extensibility and separation of concerns
- Tamper-evident file metadata validation and secure overwrite protocols

### [Code-Sentinel](https://github.com/nishantwhat/code-sentinel)
**AI-driven code review system for vulnerability detection**
- **Contribution scope**: Research, system design documentation, and architectural guidance
- AST parsing and semantic dependency graph construction for context-aware analysis
- Multi-agent reasoning framework with local LLM inference and hybrid retrieval strategies
