## 🏗️ Project System

<details open>
<summary><b>API Abuse Detection Engine</b></summary>

**Problem:** Detecting Layer-7 attacks from high-dimensional request logs in real-time

**Architecture:**
- Feature extraction: lexical, behavioral, request-level statistical properties
- Classification: Logistic Regression, Random Forest, Gradient Boosting ensemble
- Evaluation: F1, Precision, Recall, ROC-AUC, confusion matrix analysis

**Key Technical Decisions:**
- Nested JSON parsing for complex HTTP payloads
- Behavioral windowing for temporal attack patterns
- Hyperparameter tuning via grid search + cross-validation

**Status:** Active — production-grade ML pipeline

**Repo:** [api-abuse-detection](https://github.com/nishantwhat/api-abuse-detection)

</details>

<details open>
<summary><b>SecureFS — Cryptographic File System</b></summary>

**Problem:** Building a file system with authenticated encryption, tamper-evidence, and secure deletion

**Architecture:**
- Encryption: AES-256-GCM with PBKDF2 key derivation
- Key management: Iteration tuning for resistance against brute-force attacks
- Secure deletion: Overwrite protocols for preventing data recovery

**Key Technical Decisions:**
- Interface-driven modular design for extensibility
- Authenticated encryption for combined confidentiality + integrity
- Tamper-evident metadata validation

**Status:** Evolving — active development and security hardening

**Repo:** [securefs](https://github.com/nishantwhat/securefs)

</details>
